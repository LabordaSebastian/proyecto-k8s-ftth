# Herramientas

Esta sección documenta las **herramientas auxiliares de código abierto** que se utilizan en el proyecto para mejorar la productividad, la colaboración con asistentes de IA y la calidad del trabajo general.

No son componentes del clúster Kubernetes, sino utilidades que se instalan una vez y facilitan el desarrollo, la documentación y el análisis del repositorio.

| Herramienta | Propósito |
|---|---|
| [Codegraph](codegraph.md) | Genera un mapa estructural del repositorio para acelerar el trabajo con asistentes de IA |
