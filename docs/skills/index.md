# Skills del Proyecto

Esta sección documenta los **workflows y guías de trabajo** que se utilizan para mantener el proyecto de forma consistente. Están pensadas como herramientas de trabajo interno: instrucciones que definen cómo se hacen las cosas en este repositorio, no solo qué cosas se hacen.

!!! info "¿Qué es una Skill en este contexto?"
    Una Skill es una guía de referencia rápida que codifica el conocimiento acumulado sobre cómo realizar una tarea recurrente de forma eficiente y consistente. En este proyecto se usan en combinación con el asistente de IA (Antigravity) para producir trabajo de calidad uniforme sin necesidad de redescubrir las convenciones cada vez.

| Skill | Propósito |
|---|---|
| [Guía de Estilo de Documentación](doc-style-guide.md) | Convenciones, plantillas y proceso para documentar cualquier cambio del proyecto |
